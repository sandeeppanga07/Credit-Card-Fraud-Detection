# Credit-Card-Fraud-Detection
# Credit Card Fraud Detection Dashboard | Power BI

##  Project Overview

This project presents an interactive **Credit Card Fraud Detection Dashboard** developed in **Microsoft Power BI** to analyze transaction data, identify fraudulent activities, and provide actionable insights for financial institutions. The dashboard transforms raw transaction records into meaningful visualizations that help detect fraud patterns, monitor transaction behavior, and support data-driven decision-making.


Objectives

* Detect fraudulent transactions using transaction analytics.
* Monitor fraud trends across merchant categories and transaction hours.
* Analyze customer demographics and transaction behavior.
* Identify high-risk merchants and suspicious activities.
* Provide an interactive dashboard for fraud investigation and business intelligence.

## Dataset

The dataset contains **10,000 credit card transactions** with multiple attributes, including:

* Transaction ID
* Transaction Amount
* Transaction Date & Time
* Merchant Category
* Card Type
* Cardholder Age
* Device Trust Score
* Transaction Hour
* Foreign Transaction Status
* Location Mismatch
* Fraud Status (Target Variable)
